# MergeGraph 项目计划摘要（公开版）

本文件根据内部阶段性计划整理，删除了原始截图、个人过程记录、本机路径和未公开运行数据，只保留产品目标、架构边界和实施状态。

## 产品定位

MergeGraph 面向科研和 AI 创作团队，提供一个本地优先的项目上下文管理器。项目目录是核心单位，图片、视频、文档、源码、架构图和 AI 运行结果都通过稳定 ID、哈希、证据和谱系关联起来。

## 核心闭环

```text
本地项目目录
  -> 只读扫描与快照
  -> 文件索引与敏感项排除
  -> 证据打包
  -> AI 结构化分析
  -> 架构图校验与交付
  -> 无限画布投影
  -> 发展建议和可复核证据
```

## 数据边界

- 源目录默认不复制、不修改、不执行。
- 项目文件使用相对路径、内容哈希、语言、大小、行数和排除原因建索引。
- `.env`、私钥、证书、token、password 和疑似凭据不进入外部 AI 证据包。
- 外部 AI 只有在项目级隐私授权和单次请求授权都成立时才可使用。
- API Key 只在本地 Provider 配置中使用；前端和运行记录只保存配置状态，不回显完整密钥。
